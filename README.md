# 果物インストラクター 認定試験対策テキスト

Geminiで作成した試験対策テキストを、教科書風のインタラクティブな学習Webアプリに整理したものです。

## 機能

- **目次ナビゲーション** — 左サイドバーから全6章・各項目へジャンプ
- **章・項目ごとのページ** — 見出し・色分け・タグ（必須 / 重要 / 試験頻出）付き
- **復習リスト** — ⭐ボタンで項目をブックマーク（ブラウザに保存）
- **図表・グラフ** — カロリー比較バーチャート、真果/偽果図、旬カレンダー、都道府県ランキングなど
- **戻るボタン** — 章トップ・前後の項目・トップページへ移動

## 使い方

1. `index.html` をブラウザで開く
2. トップページから章を選ぶ、または左の目次から項目を選ぶ
3. 覚えたい項目は「☆ 復習リストに追加」をクリック
4. 右上の「⭐ 復習リスト」から復習項目を一覧表示

## ファイル構成

```
index.html       … メインHTML
css/style.css    … 教科書風スタイル
js/content.js    … 全6章のコンテンツデータ
js/app.js        … ナビゲーション・復習リスト機能
```

## 公開URL

- **本番**: https://kudamono-instructor.vercel.app
- スマホのブラウザで開き、ホーム画面に追加するとアプリのように使えます

## ローカルサーバー（任意）

```bash
# Python
python3 -m http.server 8080

# または npx
npx serve .
```

ブラウザで http://localhost:8080 を開いてください。
